# cc-usage-panel 介绍（给视频制作用）

> 读者：负责做 60～90 秒介绍视频的人或 AI。功能以本文为准，没写的功能不要加进视频。

## 一句话

**cc-usage-panel 是一个 Claude Code 插件：在桌面版侧边面板里，按天画出你的 token 用量，能按账号、项目、模型拆开看。**

## 解决什么问题

官方用量页只有「5 小时」和「每周」两条百分比进度条。它回答不了这几个问题：

- 今天、这周每天到底用了多少 token？
- 这些 token 花在哪个项目上？用的是哪个模型？
- 有好几个账号时，每个账号各用了多少？

cc-usage-panel 读本机的 Claude Code 会话记录，把这些答案直接画在侧边栏里。

## 功能清单

| 功能 | 说明 |
|---|---|
| 常驻按钮 | 输入框右下角一直有一个「用量 · 今天 xx」按钮，点一下打开面板，再点一下关闭 |
| 五个数 | 面板顶部：今天、近 7 天、日均、最多的一天、全部总量 |
| 切换 | 账号；范围（7 天、14 天、30 天、全部）；指标（等效 token、原始总量、输出）；分组（按账号、按项目、按模型） |
| 堆叠柱状图 | 每天一根柱子，按所选分组上色堆叠，始终铺满边栏宽度；鼠标停在柱子上时，图顶部弹出当天各组的明细、占比、输出量和调用次数，移开就收起 |
| 每日明细表 | 图下面的表格，按天列出数字；把边栏拉宽，表跟着放大，柱状图跟着变宽 |
| 网页版 | 一键在浏览器里打开完整报告 |
| 刷新 | 只有点「刷新」时才重新统计，平时不在后台跑 |
| 检查更新 | 点一下就把更新做完：有新版就下载并重新加载插件 |
| 单账号自动简化 | 只有一个账号时，账号切换自动隐藏 |

## 「等效 token」是什么

不同类型的 token 消耗差别很大，直接相加会失真。等效 token 按下面的权重折算：

| 类型 | 权重 |
|---|---|
| 普通输入 | ×1 |
| 缓存读取 | ×0.1 |
| 缓存写入 | ×2 |
| 输出 | ×5 |

这样算出来的数更接近真实消耗。但官方的额度算法没有公开，**等效 token 只作参考，不等于官方额度**。视频里提到时要带上这句。

不想折算的话，指标可以切到「原始总量」（各类 token 直接相加）或「输出」。

## 安装和更新

需要 **Python 3.8 或更高版本**（插件用它扫会话记录）。

**命令行**（在 Claude Code 里输入）：

```
/plugin install cc-usage-panel --marketplace <你的 GitHub 用户名>/cc-usage-panel
```

**桌面版**：点输入框旁边的 **+** → **Plugins** → **Add marketplace**，填 `<你的 GitHub 用户名>/cc-usage-panel` → 再 **Add plugin** 选 cc-usage-panel。

**更新**：打开面板，点「检查更新」，会自动下载新版并重新加载。

> `<你的 GitHub 用户名>` 是占位符，仓库发布后替换成真实地址。

## 视频分镜（约 86 秒，8 镜）

画面建议用演示数据录屏；如果用真实数据，录之前把账号名、项目名换成中性的（如「账号 A」「项目 1」），不要露出个人信息和本机路径。

| # | 时长 | 画面 | 旁白 | 屏幕字幕 |
|---|---|---|---|---|
| 1 | 0–8 秒（8 秒） | 官方用量页，两条百分比进度条，镜头推近，进度条旁打一个问号 | 「Claude Code 只告诉你用了百分之多少，可你今天到底用了多少 token？」 | 只有百分比，看不到 token |
| 2 | 8–18 秒（10 秒） | 镜头移到输入框右下角的「用量 · 今天 xx」按钮，鼠标点一下，侧边面板滑出 | 「装上 cc-usage-panel，输入框右下角多了一个按钮，点一下就能看。」 | 点一下开，再点一下关 |
| 3 | 18–29 秒（11 秒） | 面板顶部五个数依次高亮：今天、近 7 天、日均、最多的一天、全部总量 | 「今天、这周、日均、峰值、总量，五个数一眼看完。」 | 今天 / 近 7 天 / 日均 / 最多的一天 / 全部 |
| 4 | 29–42 秒（13 秒） | 堆叠柱状图；鼠标在几根柱子上移动，图顶部的卡片跟着换成当天的各组明细、占比、输出和调用次数 | 「每天一根柱子，鼠标放上去，当天花在哪、占多少、调用了几次，都在这儿。」 | 悬停看当天明细 |
| 5 | 42–55 秒（13 秒） | 分组从「按账号」切到「按项目」再到「按模型」，柱子颜色随之重排；范围从 7 天切到 30 天 | 「按账号、按项目、按模型，随时切换；7 天到全部历史，随便看。」 | 账号 · 项目 · 模型 / 7 · 14 · 30 天 · 全部 |
| 6 | 55–65 秒（10 秒） | 指标切到「等效 token」，旁边弹出权重小卡片：缓存读 ×0.1、缓存写 ×2、输出 ×5 | 「默认用等效 token，把缓存和输出折算进去，更接近真实消耗。」 | 等效 token 仅供参考，官方算法未公开 |
| 7 | 65–76 秒（11 秒） | 把边栏拖宽，柱状图跟着铺满变宽，每日明细表一起放大；再点「网页版」，浏览器打开完整报告 | 「边栏拉宽，图表跟着变大；想细看，一键打开网页版报告。」 | 每日明细表 · 网页版报告 |
| 8 | 76–86 秒（10 秒） | 黑底白字显示安装命令，下方三行小字：只读本机记录、不占上下文、点「检查更新」一键升级；最后停在插件名 | 「一行命令装好，数据只在你自己电脑上。cc-usage-panel。」 | `/plugin install cc-usage-panel` · 需要 Python 3.8+ |

节奏可以在 60～90 秒之间伸缩：要压到 60 秒，合并第 6、7 镜，并把每镜缩短 1～2 秒。

## 常见问题

**会不会联网？**
不会。只读本机文件，只有点「检查更新」时会联网去拉新版本。不读登录令牌。

**占不占对话上下文？**
不占。面板是插件界面，统计结果不会塞进和 Claude 的对话里。

**数据存在哪？**
`~/.claude/cc-usage-panel/` 下，包括统计缓存和网页报告。都在本机。

**第一次统计为什么慢？**
第一次要把全部会话记录扫一遍，记录多的话要等一会儿。之后有缓存，只扫新增的部分，一般一秒左右。

**多个账号怎么分？**
插件在每个会话启动时记下当前登录的是哪个账号。装插件之前的历史记录没有这个标记：只有一个账号时，全部算给它；有多个账号时，分不清的那部分归为「未标记」。

**和官方用量页冲突吗？**
不冲突。官方页看的是额度还剩多少；这个面板看的是 token 每天花在哪。两个一起用。
